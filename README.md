##🛍️ Retail Sales Analytics & Demand Forecasting System

##📌 Project Overview

This project is a Retail Sales Analytics and Forecasting System built using Python.
It analyzes sales data, generates insights, and predicts future sales using a machine learning model.

---

##🚀 Features

- Total Sales Calculation
- Monthly Sales Analysis
- Product-wise Sales Analysis
- Store-wise Sales Analysis
- Demand Forecasting using Linear Regression
- Data Storage using SQLite Database

---

##🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- SQLite
